SliderMC Command Cheat Sheet

Firmware V1.0
DIN A4 · ASCII protocol

S — Set (session)

ShortPhraseDescription
SSSet SpeedCruise speed mm/s (≤ max_speed_1); bare reloads init_speed; live on next fill (incl. MJ). Dual MT: axis1=session, axis2×ratio.
SASet AccelPeak accel mm/s² (≤ max_accel_1); bare reloads init_accel; live on next fill (incl. MJ). Dual MT: same ratio scaling as SS.
SESet EnableDriver enable 0|1; bare toggles; required before motion; off = hard stop.
STSet TerminalTerminal Mode 0|1; bare toggles; local echo + UART sniff to USB (expert).
SVSet VerboseVerbose #… push 0|1; bare toggles; ~3 Hz (rate via verbose_rate_hz).
SDSet DebugUSB-only debug level 0..5; bare restores default; never on UIC UART.
SLSet LeftSession soft min (working window); bare→slider_min_N; none clears (→envelope if set); skip _; !E:limit past envelope.
SRSet RightSession soft max; bare→slider_max_N; none clears; skip _; !E:limit if left>right.
SPSet PositionSet reported pose (no motion); idle only; bare/0 = here is zero; skip _.

G — Get (session)

ShortPhraseDescription
GSGet SpeedCurrent session cruise speed.
GAGet AccelCurrent session acceleration.
GEGet EnableDriver enable state.
GTGet TerminalTerminal Mode state.
GVGet VerboseVerbose push state.
GDGet DebugUSB debug level.
GLGet LeftSession soft min; effective (session else envelope); - if both None; extra fields when axis≥2.
GRGet RightSession soft max; same effective / - rules as GL.

I — Is / status

ShortPhraseDescription
IMIs MovingMoving or settling on any active axis.
IHIs HomingHoming cycle active.
ILIs LimitAt soft-limit position (axis1).
IEIs ErrorPIN_DRV_ERROR / EMO latched.
IPIs PositionOne field per live axis (CG axis).
IAIs AxisLive axis count (CS axis / CG axis).
ITIs TargetAxis-1 seek target, or - if none / soft-stop.
IRIs Ready1 only if idle, not homing, enabled, and not waiting.
IWIs Waiting1 if any WT / WM / WH / WP / WC / WN wait is active.
IDIs DiagMotion diag counters (FIFO underrun, peak STEP Hz, …).
ICIs CauseLast chip reset: power|wdt|run|soft|debug|brownout|…
IGIs GPIOASCII GP / name / desc (≤80 cols). Extra-axis rows only if that axis is live.

M — Movement

ShortPhraseDescription
MTMove ToAbsolute user units; extra live axes; skip _; needs SE; live-retarget. Dual: time-sync ratio. Out-of-window = !E:soft (no clip).
MBMove ByRelative move; same extra-axis/skip/named rules as MT.
MJMove JoyJoy speed % of SS, signed (− left / + right); omit named extra=0; 0=soft-stop; SS/SA live; clamp max_speed_N. Hold-to-jog: MJ ±100, MS on release.
MHMove HomeHoming; axis 1 (default), 2, or 3; no-op if home_mode_N=0; cancel MS/HT.
MSMove StopSoft decelerate both axes; keeps enable; ends joy-mode; does not cancel waits. Dual: scaled accel kept.

P — Path

ShortPhraseDescription
PCPath ClearClear path buffer (count→0); !E:busy while PG active.
PDPath DataAppend signed µm sample(s); extra live axes; skip _ →0; OK while PG (live stream).
PGPath GoPlay buffer from sample 0; needs SE; !E:empty|busy|disabled. MS/HT ends path.
PNPath NumberSamples in buffer; allowed during PG.
PSPath SliceSlice length µs (≥1000); bare→init_path_slice_us; !E:busy while PG.

E — Extender / beep

ShortPhraseDescription
EOExt OutExt out n logical 0|1; bare EO0 toggles; glued EO01≡EO0 1; OK during EMO. EO4+ rejected.
BEBeepPulse PIN_BUZZER ~0.1 s; not a wait. No-op if BUZZER_use=0. OK during EMO/path.

C — Config

ShortPhraseDescription
CSConfig SetPersist key to mc.ini; silent ok. axis / WDT_use need RB to take HW effect.
CRConfig ResetReset all config to compiled defaults and save mc.ini.
CGConfig GetOne key, or bare dumps all keys (multi-line).
RBRebootSoft MCU reset (no power cycle); EN off first. After CS axis.

W — Wait

ShortPhraseDescription
WTWait TimeDelay then continue ; chain; bare→1 s; never !E:timeout.
WMWait MovingPause chain until move ends; optional timeout → !E:timeout, cancel rest of chain.
WHWait HomingPause until homing ends; timeout same as WM.
WPWait PosWait until axis-1 pos reached/overstepped; idle→immediate; 2nd arg=timeout.
WCWait CruiseWait until cruise (status M) or idle; optional timeout → !E:timeout.
WNWait Not cruiseWait until not cruise M; idle/A/B→immediate; timeout same as WM.

V — Version

ShortPhraseDescription
VAVersion AboutAbout string (name, version, author).
VFVersion FWFirmware version.
VPVersion ProtocolProtocol version (2).

Special

ShortPhraseDescription
HTHaltImmediate STEP abort; enable off; cancel waits and remaining ; chain.
VGVersion GPIOMachine-readable pin map. Extra-axis pins if that axis is live.
HL/$HelpTwo-column table of all commands (short + phrase).
?/#Status nowRealtime compact status line (no newline).
!/ESCSoft stop nowRealtime soft stop (same urgency as MS).
Wire: one command per line (\n); chain with ;; axis args positional or named X/Y/Z (glued MTX20Y50Z100 ok); # is realtime status, not a comment; bare bool setters toggle; motion/settings silent on success; errors !E:code message.
Realtime (no newline): ?/# status · !/ESC soft stop · Ctrl-X (0x18) soft reset.
Status (#X …): I idle · A accel · M cruise · B decel · H homing · P path · L hard-limit · D disabled · E error. Moving: #M/#A/#B pos speed accel [target].
Halt vs Stop: MS/!/ESC soft decel (enable kept, ends joy-mode); HT immediate abort, enable off, cancel waits. MJ: skip if value unchanged. Hold-to-jog: MJ ±100, MS on release.
