Legend: SPEED on GP26; optional ACCEL on GP27; UART to SliderMC on GP16 (TX) / GP17 (RX) @ 115200 baud.
Motion STEP/DIR/EN, SW_LIMIT_*, DRV_ERROR live on the SliderMC Pico — not on this UIC.
B4Slider: SET / MOVE_L / MOVE_R / OPTION plus AXIS_1..6 (GP12/11/10/9/8/22).
  Legal AXIS selection: packed getAxisCount() (motors+servos, up to 6).
  SPEED pot GP26; optional ACCEL pot GP27 (B4S_SPEED_INPUT / B4S_ACCEL_INPUT).
  Optional QD: ENC_SPEED GP14/15, ENC_ACCEL GP18/19 (pin_b = pin_a+1).
  No keypad, FAST, A/B/C, DELAY, TIMELAPSE, joystick, or UIC camera pin.
  SET on GP5 (was STOP on JKSlider). Shutter is SliderMC PIN_CAMERA_CTRL / CT.
Shutter is SliderMC PIN_CAMERA_CTRL / CT (not a UIC GPIO). Optional NeoPixel: use a free GPIO and set PIN_NEOPIXEL.
Naming: BTN_* = electronics/pinout; User Manual uses plain names (SET, MOVE_L, …). Key silk: ` S `, ` < `, ` > `, ` * `.
