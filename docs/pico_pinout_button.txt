Legend: pots on ADC pins GP26–28; UART to SliderMC on GP16 (TX) / GP17 (RX) @ 1 Mbaud.
Motion STEP/DIR/EN, SW_HOME, DRV_ERROR live on the SliderMC Pico — not on this UIC.
Button mode: one GPIO per BTN_* (active-low). JKS_INPUT_MODE = "button".
GP22 CTRL_CAMERA = shutter / intervalometer (PIN_CTRL_CAMERA). Optional NeoPixel: use a free GPIO (GP18–21) and set PIN_NEOPIXEL.
Naming: BTN_* = electronics/pinout; User Manual uses plain names (STOP, MOVE_L, …). Key silk: short labels (` > `, ` * `, …).
