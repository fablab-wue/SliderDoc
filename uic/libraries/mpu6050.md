# MPU6050 API

MicroPython I2C reader for the **MPU6050** 6-axis IMU (accel + gyro), aimed at hand-held tilt sensing. Implementation: [`MPU6050.py`](../MPU6050.py).

Defaults: **I2C0**, **GP0** SDA / **GP1** SCL, address **`0x68`**, host sample **25 Hz** (`interval_ms=40`), on-chip **DLPF=4**, EMA on accel. `getTilt()` / `getRoll()` are **accel-only** angles in degrees (**0° = upright**, chip **+Z up**). Deadzone and tilt→speed mapping belong in the application.

---

## Class `MPU6050`

### Constructor

```python
MPU6050(i2c_id=0, pin_SDA=0, pin_SCL=1, addr=0x68, auto=True, interval_ms=40, callback=None)
```

| Arg | Default | Meaning |
|-----|---------|---------|
| `i2c_id` | `0` | Hardware I2C controller |
| `pin_SDA` | `0` | I2C SDA GPIO |
| `pin_SCL` | `1` | I2C SCL GPIO |
| `addr` | `0x68` | 7-bit address (`0x69` if AD0 is high) |
| `auto` | `True` | Prefer asyncio background sampling (`await start()`) |
| `interval_ms` | `40` | Async poll period (~25 Hz) |
| `callback` | `None` | Optional callable `fn(imu)` after each successful sample |

Init wakes the chip, sets ±2 g / ±250 °/s, `DLPF_CFG=4`, `SMPLRT_DIV=39`, and checks `WHO_AM_I` (expects `0x68`).

### Public members

| Member | Type | Meaning |
|--------|------|---------|
| `accel_x`, `accel_y`, `accel_z` | `float` | Acceleration in **g** (EMA-smoothed) |
| `gyro_x`, `gyro_y`, `gyro_z` | `float` | Angular rate in **°/s** (DLPF only) |
| `callback` | callable or `None` | Optional update hook (see below) |

### Methods

| Method | Role |
|--------|------|
| `poll()` | Read one sample; update public axes |
| `async start()` | Start asyncio sample loop at `interval_ms` |
| `async stop()` | Cancel the sample task |
| `deinit()` | Drop the I2C handle |
| `getTilt()` | Pitch about Y (°); 0 = upright |
| `getRoll()` | Roll about X (°); 0 = upright |
| `on_data()` | Hook after publics update — override in a subclass (default no-op) |

```python
tilt = atan2(-accel_x, accel_z) * 180/pi
roll = atan2( accel_y, accel_z) * 180/pi
```

With `auto=True`, call `await imu.start()`. With `auto=False`, call `poll()` about every 40 ms.

### Update hooks (`on_data` / `callback`)

At the end of each successful `poll()` (after accel EMA and gyro publics are set), the library calls `on_data()`, then `callback(self)` if set.

Keep the handler short: with `auto=True` it runs inside the asyncio sample task.

```python
class MyImu(MPU6050):
    def on_data(self):
        print(self.getTilt(), self.getRoll())

imu = MyImu(auto=True)
# or without subclassing:
imu = MPU6050(callback=lambda m: print(m.accel_z), auto=False)
```

---

## Sampling / noise

| Layer | Setting | Role |
|-------|---------|------|
| Host / asyncio | 25 Hz (`interval_ms=40`) | Matches hand-tilt bandwidth |
| Chip `DLPF_CFG` | 4 (~21 Hz accel / ~20 Hz gyro) | On-chip low-pass |
| Chip `SMPLRT_DIV` | 39 → 25 Hz sample rate | Aligns chip rate with host |
| Software EMA | α ≈ 0.35 on accel | Extra tremor smoothing for angles |

## Examples

### Sync poll (`MPU6050.py` `__main__`)

```python
imu = MPU6050(pin_SDA=0, pin_SCL=1, addr=0x68, auto=False, interval_ms=40)
next_print = time.ticks_add(time.ticks_ms(), 250)
try:
    while True:
        imu.poll()
        now = time.ticks_ms()
        if time.ticks_diff(now, next_print) >= 0:
            print(
                "A", round(imu.accel_x, 3), round(imu.accel_y, 3), round(imu.accel_z, 3),
                "G", round(imu.gyro_x, 1), round(imu.gyro_y, 1), round(imu.gyro_z, 1),
                "tilt", round(imu.getTilt(), 1),
                "roll", round(imu.getRoll(), 1),
            )
            next_print = time.ticks_add(now, 250)
        time.sleep_ms(40)
finally:
    imu.deinit()
```

### Asyncio ([`MPU6050AsyncExample.py`](../MPU6050AsyncExample.py))

Background sampling at 25 Hz; print every 250 ms.

```python
import uasyncio as asyncio
from MPU6050 import MPU6050

async def demo():
    imu = MPU6050(auto=True, interval_ms=40)
    await imu.start()
    try:
        while True:
            print(
                "A", round(imu.accel_x, 3), round(imu.accel_y, 3), round(imu.accel_z, 3),
                "G", round(imu.gyro_x, 1), round(imu.gyro_y, 1), round(imu.gyro_z, 1),
                "tilt", round(imu.getTilt(), 1),
                "roll", round(imu.getRoll(), 1),
            )
            await asyncio.sleep_ms(250)
    finally:
        await imu.stop()
        imu.deinit()

asyncio.run(demo())
```

```text
import MPU6050AsyncExample
MPU6050AsyncExample.run()
```

### Fusion (app-level) — [`MPU6050FusionExample.py`](../MPU6050FusionExample.py)

Fusion is **not** inside `MPU6050`. Use `accel_*` / `gyro_*` (or `getTilt()` / `getRoll()` as the accel measurement) in the application.

**Complementary filter** (typical α ≈ 0.96…0.98 at 25 Hz):

```text
angle = α * (angle + gyro_dps * dt) + (1 − α) * accel_angle
```

Match axes to the lib: **tilt** uses `gyro_y` with `getTilt()`; **roll** uses `gyro_x` with `getRoll()`.

**1D Kalman** (per axis): compact angle estimate driven by gyro prediction and accel angle measurement. Full 6DOF AHRS Kalman is out of scope; see the example file for a minimal MicroPython implementation that prints accel angles vs complementary vs Kalman.

## Wiring

| MPU6050 / GY-521 | Pico |
|------------------|------|
| VCC | 3V3 |
| GND | GND |
| SDA | GP0 (default) |
| SCL | GP1 (default) |
| AD0 | GND → address `0x68` (3V3 → `0x69`) |
| INT | unused |
