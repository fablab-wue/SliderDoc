B4Slider Cheat Sheet set card · AXIS 1–5 packed · silk 1 2 3 typical

Panel

Silk: S SET · < MOVE_L · > MOVE_R · * OPTION · 123 AXIS (recommended plate). Firmware also wires AXIS_4/5. Legal chord: each key ≤ packed getAxisCount(). Invalid = blue blink. Boot = axis 1. OLED Ax 1+5. Unlock: OPTION. Homing: motors only. Shutter: SliderMC CT, not a UIC pin.

Loop arm does not start motion; next MOVE cruise ping-pongs until SET / same tip / halt.

Workflows

  • Normal moving
    • Unlock with OPTION if LED is rainbow
    • Select AXIS (or leave 1); dial SPEED
    • Tap MOVE to cruise; hold MOVE to jog
    • Same tip stops; opposite reverses; SET stops; L+R halt
  • Frame A / B on selection
    • Hold the AXIS keys you are framing
    • Jog to first pose; S < tap → left ends
    • Jog to second pose; S > tap → right ends
    • Rehearse: MOVE tap cruises to that end
    • Optional loop: idle * S hold ≥1s, then MOVE tap
