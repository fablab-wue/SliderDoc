B4Slider Cheat Sheet set card

Panel

Silk: S SET · < MOVE_L · > MOVE_R · * OPTION. ACCEL pot is optional (B4S_USE_ACCEL_POT). Unlock at boot: press OPTION (rainbow LED).

Soft limits (A / B window)

ActionKeyDescription
SET + MOVE_L tapS < tapSet soft_limit_L here
SET + MOVE_R tapS > tapSet soft_limit_R here
SET + MOVE_L hold ≥1sS < hold ≥1sReset L → slider min
SET + MOVE_R hold ≥1sS > hold ≥1sReset R → slider max
SET + L + R hold ≥1sS < > hold ≥1sReset both ends

Travel only inside the working window. MOVE cruise targets those ends (A / B).

SET / OPTION

ActionKeyDescription
SET tap (idle)S tapNothing
SET hold ≥1s (idle)S hold ≥1sAccel preset L — no ACCEL pot
SET hold ≥3s (idle)S hold ≥3sAccel preset H — no ACCEL pot
SET hold ≥5s (idle)S hold ≥5sAccel learn from SPEED pot — no ACCEL pot
OPTION + SET tap* S tapDisable driver
OPTION + SET hold ≥1s* S hold ≥1sToggle loop armed
Any key while disabled—Re-enable driver

Loop arm does not start motion; next MOVE cruise ping-pongs until SET / same tip / halt.

Pots

ControlDescription
SPEEDLeft → slower floor; right → faster (finer at low end)
ACCELIf B4S_USE_ACCEL_POT=1: left gentler / right snappier. SET accel holds off.

Workflows

  • Normal moving
    • Unlock with OPTION if LED is rainbow
    • Dial SPEED (and ACCEL pot, or SET 1s/3s presets if no pot)
    • Tap MOVE to cruise to a soft end; hold MOVE to jog
    • Same tip stops; opposite reverses; SET stops; L+R halt
  • Frame A / B
    • Jog to first pose; S < tap → soft_limit_L
    • Jog to second pose; S > tap → soft_limit_R
    • Rehearse: MOVE tap cruises to that end
    • Optional loop: idle * S hold ≥1s, then MOVE tap
