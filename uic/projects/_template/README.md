# UIC project template

Copy this folder when adding a new SliderCtrl panel application.

```text
_template/
├── user-manual.md       # Operator guide
├── technical/README.md  # Installer hub
├── panel-layouts/       # Pinout PNG/SVG
└── cheat-sheet/         # Printable quick reference
```

1. Duplicate `_template/` to `uic/projects/<your-app>/`.
2. Fill placeholders; link shared docs ([contract/](../../../contract/README.md), [components/](../../../components/README.md)).
3. Add a row to [projects/README.md](../README.md).
