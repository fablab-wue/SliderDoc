Timelapse

ActionKeyDescription
TIMELAPSE tapT tapCycle divider 1…100
TIMELAPSE hold ≥1sT hold ≥1sBack to ×1

TL×1 & continuous: CTRL_CAMERA high while moving / soft-paused; low when idle. OLED: MSM xN @Ffps / Cont xN @Ffps.

Timelapse workflows

  • Plan the path
    • Frame: store PosA / PosB (PosC if needed)
    • Rehearse A→B at TL×1; dial SPEED/ACCEL until pacing feels right
    • MSM: SPEED = hop speed (interval = N/FPS). Continuous: crawl = SPEED÷N
    • Toggle MSM ↔ continuous (* D T); set TL; shoot
  • MSM
    • Wire GP22 shutter (optocoupler); manual exposure/focus
    • Plan at ×1; optional DELAY arm; DELAY hold soft-pauses (freezes take)
    • MSM + TL; OLED MSM xN @Ffps; FPS via OPTION+STOP
    • Start camera stills/REC
    • Shoot: B / MOVE / loop (pulse → hop → settle)
    • Stop REC; TL too fast / Step slow if hop won’t fit
  • continuous
    • Same wire (hold-high, not pulses)
    • Plan at ×1; match camera TL to slider TL
    • Continuous + TL; OLED Cont xN @Ffps (OPTION+STOP peeks marks only)
    • Start camera REC before the move
    • Shoot: B / MOVE / loop (crawl ÷N); soft-pause keeps pin high
    • Stop REC when idle / after STOP
