# tb6612 — TB6612FNG

`CS motor_n_driver tb6612`

`DRV_C` is PWMA. `DRV_D` is STBY (high = run). `auto` sense is off. VM on the Toshiba chip is about 4.5–13.5 V. The output is about 1 A continuous per channel, higher peak.

| | |
|---|---|
| Supply | about 4.5–13.5 V (VM); logic 2.7–5.5 V |
| Current | about 1.2 A continuous, 3.2 A peak, per the TB6612FNG |
| Active brake | yes |
| Hand release | yes — STBY low |
| Current limit | no |
| Error input | no |

Duty 0 sets IN1 and IN2 high, PWMA low, and STBY high. On the TB6612FNG truth table, IN1=IN2 high is a short brake for either PWM level. `SE 0` drives STBY low and the outputs go high-impedance. Both inputs low with PWM low is the coast row; this preset does not use that row while the axis is enabled.

```text
DRV_A_n ---- AIN1
DRV_B_n ---- AIN2
DRV_C_n ---- PWMA
DRV_D_n ---- STBY
```
