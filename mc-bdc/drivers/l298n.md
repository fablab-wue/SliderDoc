# l298n

`CS motor_n_driver l298n`

Remove the ENA jumper. No external inverter. `DRV_A` and `DRV_B` are IN1 and IN2. `DRV_C` is ENA. `auto` sense is off. 3.3 V is a valid high. About 2 V is lost in the bridge, so a 12 V motor sees less.

| | |
|---|---|
| Supply | typically 5–35 V on the module; the motor voltage is that minus about 2 V |
| Current | modules are often sold as 2 A per channel; the chip drops more as current rises |
| Active brake | yes — both inputs high and ENA high |
| Hand release | yes — ENA low |
| Current limit | no |
| Error input | no |

`SE 0` holds ENA low, so the outputs are off and the shaft can be turned. Duty 0 while enabled drives both inputs high and ENA high (short brake).

```text
DRV_A_n ---- IN1
DRV_B_n ---- IN2
DRV_C_n ---- ENA    (jumper removed)
```
