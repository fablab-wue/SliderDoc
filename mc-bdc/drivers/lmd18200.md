# lmd18200

`CS motor_n_driver lmd18200`

TI LMD18200, a 3 A, 55 V H-bridge. `DRV_A` is PWM, `DRV_B` is DIR, `DRV_C` is BRAKE. The chip has an internal charge pump, so 100% duty is allowed. PWM on this preset is 10 kHz. A second motor that shares that PWM slice also runs at 10 kHz.

| | |
|---|---|
| Supply | up to 55 V (about 12 V minimum for the charge pump) |
| Current | 3 A continuous, 6 A peak |
| Active brake | yes |
| Hand release | yes |
| Current limit | yes, after `motor_n_i_per_v` is set |
| Error input | yes, if the thermal flag is wired instead of current sense |

Duty 0 is PWM low and BRAKE low. That truth-table row turns both high-side drivers on and shorts the motor. `SE 0` is PWM low and BRAKE high, the row the datasheet calls NONE, so the shaft freewheels. BRAKE high with PWM high is the other short (both low sides). This firmware uses the high-side short at duty 0.

The current-sense pin sources about 377 µA per amp into a resistor to GND. `auto` sense is current, and `i_per_v` stays 0 until you set it: `i_per_v = 1 / (377e-6 × R)`. Keep the pin at or below 3.3 V. The thermal flag is active-low open drain. Use it by setting `motor_n_sense error` instead of current. One pin, so pick one.

```text
DRV_A_n ---- PWM
DRV_B_n ---- DIR
DRV_C_n ---- BRAKE
CUR_ERR_n -- current sense (resistor to GND) or the thermal flag
```
